# 🚀 Karo Pitch Landing Page

A clean and modern landing page for **Karo Pitch**, an initiative by **KaroStartup** that helps early-stage founders across India pitch their startups directly to investors.

This project demonstrates a responsive and startup-focused landing page built using **HTML, CSS, and JavaScript** with a modern UI and engaging visuals.

---

## 🌟 About the Project

Karo Pitch aims to solve a major challenge faced by many founders in **Tier-2 and Tier-3 cities** — limited access to investors and visibility.

This landing page introduces the Karo Pitch platform and encourages founders to apply for curated startup pitch events where they can present their ideas to investors.

The design focuses on:

- Clean and modern user interface
- Simple and intuitive navigation
- Mobile-friendly layout
- Startup ecosystem aesthetics
- Professional presentation

---

## ✨ Features

- 🚀 Modern **Hero Section** introducing the platform
- 📖 **About Section** explaining the mission of Karo Pitch
- ⚙️ **How It Works** process with visual steps
- 🧩 **Startup Categories** section showing who can apply
- 🤝 **Investor Section** highlighting investor participation
- 🌱 **Featured Startups** cards showcasing sample startups
- 📰 **KaroStartup Section** explaining the parent platform
- 📢 Strong **Call-to-Action** encouraging founders to apply
- 📱 **Fully responsive design** for mobile devices
- 🎨 Clean startup-style UI with icons and animations
